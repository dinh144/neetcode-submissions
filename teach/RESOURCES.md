# NeetCode Blind 75 Visual Learning Resources

## Knowledge

- [NeetCode.io Blind 75 Roadmap](https://neetcode.io/practice/practice/blind75)
  Canonical 75 problem set organized by pattern. Use for: problem definitions, edge cases, video explanations.
- [MisterBooo/LeetCodeAnimation](https://github.com/MisterBooo/LeetCodeAnimation)
  Visual animated demonstrations of LeetCode algorithms. Use for: step-by-step mutation tracing, pointer state progression, visual intuition.
- [Python TimeComplexity Wiki](https://wiki.python.org/moin/TimeComplexity)
  Official time complexity guarantees of Python dict, set, and list operations. Use for: Big-O trade-off verification.

## Wisdom (Communities)

- [NeetCode Community Discord](https://discord.gg/neetcode)
  Active community of engineers practicing interview patterns. Use for: debugging stuck patterns and mock interview feedback.
